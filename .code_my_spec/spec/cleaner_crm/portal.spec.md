# CleanerCrm.Portal

Client-facing portal domain: magic-link session tokens for clients (no password accounts), the client's view of upcoming visits with assigned-cleaner identity, service history with proof-of-work, and self-service reschedule/cancel enforcement against the account's cancellation policy.
